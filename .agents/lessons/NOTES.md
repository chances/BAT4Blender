# Teaching Notes

- Use Title Case for headings and titles in authored content.
- After a colon in bullet text, capitalize the next word when it starts a sentence.
- HTML lessons and references should honor the system or browser `prefers-color-scheme`; do not force a light-only page.
- HTML lessons and references should use the supplied SimCity 4 GUI as their visual cue: Aqua-gray panels, navy labels, solid fills, and red/green status accents. Avoid gradients, boxed component borders, and contrasting fills on regular content sections.
- Keep teaching records in `.agents/lessons/` and end-user documentation in [docs](../../docs/index.html).
