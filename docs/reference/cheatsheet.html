Cheatsheet

From Scene to Export

A compact checklist for rendering a SimCity 4 BAT from Blender.

Before Rendering

  1. Save the Scene

    Exports are written beside the saved .blend file.

  2. Choose Cycles

    Use Properties → Render → Render Engine → Cycles.

  3. Set Up Lighting and Compositing

    In Properties → Scene → BAT4Blender, click World, then Compositing.

  4. Create LODs

    Click Add to create missing LOD meshes. After changing the model, choose a zoom and click Fit Z… to refit that LOD.

Preview, Then Render

  • Set the selected Zoom, Rotation, and Day/Night, then click Preview.
  • In the Render Result, select Composite to see the compositor output.
  • Click Render all zooms & rotations. The default Day-only selection produces five zoom levels across four rotations.
  • Generated OBJ, PNG, and XML files are placed beside the saved .blend file.

Optional Tools

  • Super-Sampling: Enabled by default. It renders at 2× resolution and downsamples. Install ImageMagick or disable this option.
  • Post-Processing: Off by default. Enable it and set the fshgen executable path to create an .SC4Model.
  • Day/Night collections: Objects in collections named Day or Night can be shown or hidden automatically for those passes.

Before Setup: Save a copy of the scene. BAT4Blender adds a helper collection, LOD meshes, and a camera.
