# Mission: Use BAT4Blender

## Why
Learn to take a Blender scene through BAT4Blender's render and export workflow for a SimCity 4 model.

## Success Looks Like
- Set up a scene and inspect a useful preview.
- Render the model's zoom and rotation views, then locate the exported files.
- Create an SC4Model file when the optional post-processing tools are installed.

## Constraints
- Teach one short, practical step at a time.
- The Blender scene may need to be saved before export.

## Out of Scope
- Editing BAT4Blender's source code or automating batch exports.
