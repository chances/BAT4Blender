Getting Started

Prepare a Blender scene, preview a view, and export a SimCity 4 BAT.

Requirements

  • Blender 3.6, 4.2+, or 5.0+.
  • Cycles for rendering.
  • ImageMagick for Super-Sampling, which is enabled by default.
  • fshgen for optional SC4Model post-processing.

Installation

  1. Download the Add-on

    Get the latest BAT4Blender ZIP from the release page.

  2. Install the ZIP in Blender

    Open Edit → Preferences → Add-ons, choose Install from Disk, and select the ZIP.

  3. Open the BAT4Blender Panel

    Find it under Properties → Scene → BAT4Blender.

Prepare the Scene

  1. Save the Blender File

    BAT4Blender writes output beside the saved .blend file. Save before rendering to choose the output folder.

  2. Set the Render Engine

    Choose Cycles under Properties → Render → Render Engine. The World setup also switches EEVEE to Cycles.

  3. Check Output Dimensions

    In Output Properties, set Resolution Scale to 100% and Pixel Aspect to 1:1.

  4. Load the World and Compositor

    Click World, then Compositing in the BAT4Blender panel. Run World first because the compositor setup uses its light group.

  5. Create and Fit LODs

    Click Add to create missing Level of Detail (LOD) meshes. BAT4Blender fits them to the bounds of render-visible mesh objects. After changing the model, select a zoom and click Fit Z… to refit that LOD.

The Camera button positions the camera for viewport inspection. BAT4Blender positions it automatically during preview and export.

Preview a View

  1. Select the View

    Choose a Zoom, Rotation, and Day/Night mode in the BAT4Blender panel.

  2. Render the Preview

    Click Preview to render the selected view.

  3. Inspect the Composite

    In the Render Result, select Composite rather than View Layer. The composite shows the add-on's lighting and post-processing.

Render and Export

Choose the output modes from the Day/Night menu, then click Render all zooms & rotations. The default Day-only selection renders 20 views across five zoom levels and four rotations.

Press Esc to cancel a running batch.

Generated Files

  • .obj files contain exported LOD geometry.
  • .png files contain rendered model views.
  • .xml contains the SC4PLUGINDESC descriptor and remains separate from the SC4Model file.
  • .SC4Model is created when Post-Processing is enabled and fshgen is configured.

Day and Night Output

The Day/Night menu selects which lighting modes the batch renders. Day only is the default. Maxis Night (MN) and Dark Night (DN) can be added to a day render or rendered separately.

Post-Processing requires a Day render. MN-only and DN-only batches cannot create an SC4Model.

To control object visibility, place objects in collections named Day or Night. BAT4Blender enables the matching collections for each render mode.

Optional Tools

Super-Sampling

Super-Sampling is enabled by default. It renders at 2× resolution and downsamples the result. Install ImageMagick and set its executable in BAT4Blender preferences, or disable Super-Sampling.

Post-Processing

Post-Processing is disabled by default. Install fshgen and set its executable in BAT4Blender preferences to create an SC4Model. BAT4Blender removes the intermediate OBJ and PNG files after conversion.

Troubleshooting

The renderer reports an unsupported resolution scale or pixel aspect.
Set Resolution Scale to 100% and Pixel Aspect to 1:1 in Output Properties.
The preview does not show night lighting or compositor effects.
Choose Composite in the Render Result.
Super-Sampling or SC4Model conversion fails.
Set the ImageMagick or fshgen executable path in BAT4Blender preferences. Disable the corresponding option to continue without that tool.
The output files are not where expected.
Save the .blend file first. BAT4Blender writes output beside it.
